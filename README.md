# Dimasa · Motor de abastecimiento

Herramienta interna para decidir qué, cuánto y cuándo comprar: diagnóstico de inventario, matriz ABC-XYZ, forecast de demanda y propuesta de compra semanal.

Stack: React + Vite + Tailwind, Supabase, Vercel.

## Desarrollo local

1. `npm install`
2. Crear `.env.local` con `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY`
3. `npm run dev`
